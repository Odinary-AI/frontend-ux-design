# 动效决策与参数

本文件是动效默认策略的唯一正文。先遵循项目既有约定；设计契约引用选定值，评审按用途与实际影响检查。

## 先决定是否需要

1. 说明用途：反馈输入、解释状态/空间变化，或服务明确的品牌表达。没有目的就不用。
2. 考虑频率：高频输入、快捷操作、数据核对优先即时完成，避免反复等待；低频展示可以有更多表达。
3. 考虑中断：用户再次点击、关闭或反向拖拽时，从当前状态继续响应，不锁住操作等动画播完。

营销/展示可选择一次有目的的入场编排，不能每个区块都默认淡入上滑。工具/阅读不默认加页面演出。回应操作的动效同样需要判断频率和必要性，不能“凡操作必动画”。

## 默认时长与曲线

无项目参数时，从这些范围起步，再结合距离、对象大小和实际反馈调整：

| 用途 | 起始范围 |
|---|---|
| 按压等即时反馈 | 100–150ms，也可即时变化 |
| 菜单、tooltip、状态切换 | 200–300ms；高频时缩短或省略 |
| 模态、抽屉、布局变化 | 300–500ms |
| 非交互入场序列 | 默认整体不超过 500ms，包含延迟与交错；用户明确要求的长叙事需单列目的及不阻塞操作的策略 |

快速显现通常用 ease-out；平滑往返可用 ease-in-out；离场优先及时，不强制统一曲线。可用 `cubic-bezier(0.16, 1, 0.3, 1)` 和 `cubic-bezier(0.65, 0, 0.35, 1)` 作为起点，优先沿用项目 token，不按作者偏好否定项目全部 easing。

操作型控件默认避免 bounce/elastic。弹簧可用于连续手势或无过冲的状态跟随；装饰回弹需要明确用途，不引入依赖只为一个效果。popover 从触发点附近展开，居中模态不套用同一锚点。

## 连续操作与实现

- 只声明需要过渡的属性，避免 `transition: all`。优先 transform/opacity；其他属性确有用途时说明成本，不能把 grid 行高动画称为“不触发布局”。
- 可打断的状态过渡使用项目合适的 transition/运动组件；不让重复触发堆积队列或先跳回起点。
- tooltip 可保留首次出现延迟，连续浏览相邻触发点时缩短等待；不能牺牲键盘可访问性。
- 拖拽处理速度、边界和取消，沿现有组件行为；不要照抄固定速度阈值到所有设备。
- `will-change` 只在已知需要时短暂使用；滚动触发与测量避免无界监听、反复布局读写和不必要的动画库。

## 自动播放与持续变化

声音优先由用户主动开始。自动播放音频超过 3 秒时，提供暂停/停止，或独立于系统音量的音量控制（可静音）；声音不套用下方视觉运动的 5 秒或并行内容条件，依据 [WCAG 2.2 音频控制说明](https://www.w3.org/WAI/WCAG22/Understanding/audio-control.html)。

与其他内容并行、自动开始且持续超过 5 秒的移动、闪烁或滚动内容，除确属活动必要部分外，提供暂停、停止或隐藏机制。自动开始且与其他内容并行的更新信息，同样除必要部分外，提供暂停/停止/隐藏或更新频率控制，不套用 5 秒豁免。短循环按连续播放总时长判断，不能每次重播重新计时。适用条件依据 [WCAG 2.2 的暂停、停止、隐藏说明](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)；这不替代对闪光等其他适用风险的检查。

控件需可理解、可通过键盘操作，暂停后不被无关焦点或指针变化自动恢复；静态替代应保留重要信息。reduced-motion 是另一条适用要求，不能代替普通模式下所需的暂停控制。音视频的替代内容及素材交付见 [素材规则](assets.md)。

## Reduced motion 与反馈

存在运动时尊重 `prefers-reduced-motion`。按效果移除大幅位移、缩放、循环和装饰，保留状态、焦点、进度和完成反馈；可改为即时切换或轻量淡入。不要给所有元素套极短 duration 后就宣称降级完整，尤其不能依赖被取消的动画事件完成业务状态。

例如，对确实只承担装饰位移的元素做定向降级：

```css
@media (prefers-reduced-motion: reduce) {
  .decorative-reveal {
    animation: none;
    transform: none;
    opacity: 1;
  }
}
```

用户仍能知道发生了什么。等待反馈与乐观更新的状态和恢复要求统一见 [交互规则](interaction.md#表单与恢复)；本节只决定相关运动如何降级。

## 验证

核对首次触发、快速反向/重复触发、结束/取消与 reduced-motion。范围涉及性能时观察实际实现或测量，不因只使用 transform 就保证流畅。移动输入和滚动联动见 [交互规则](interaction.md)。没有运行证据时只报告源码可确认部分。
