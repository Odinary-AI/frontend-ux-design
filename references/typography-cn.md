# 中文字体与排版

中文设计、提取和评审按需读取。以下是没有项目规范时的起点，不是所有控件、品牌和文体的固定数值；实际可读性、字体覆盖与目标设备优先。

## 字体与回退

复用项目字体，确保目标平台缺字时仍能阅读。系统字体栈是低依赖方案；中文 web font 需核对授权、子集、加载体积和回退，不一概禁止。

```css
--font-body: "PingFang SC", "HarmonyOS Sans SC", "MiSans", "Source Han Sans SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;
--font-serif: "Songti SC", "Source Han Serif SC", "Noto Serif SC", "SimSun", serif;
--font-kai: "Kaiti SC", "STKaiti", "KaiTi", serif;
```

需要西文/数字另选字体时置于适当中文回退之前；工具界面使用已验证的 system-ui 也可成立。选择宋体、楷体等要服务文体与实际可读性，不能因命中字体名称就判定缺陷。

标题层级结合字号、字重、间距与位置建立；一套字体可覆盖全界面，不强制多字重或多字体。不能假定系统都安装同一中文字体，应核对实际回退。

## 正文与紧凑界面分开

| 参数 | 中文正文起点 | 适用说明 |
|---|---|---|
| 字号 | 15–17px，通常不低于 15px | 缩放、字形、目标设备和阅读距离影响判断；移动输入还需检查聚焦时浏览器缩放 |
| 行高 | 1.7–2.0 | 连续段落；表格、按钮和单行标签不直接套此范围 |
| 行宽 | 目标不超过约 38 个汉字 | 长文容器参考；不要用 Latin `ch` 假称精确汉字数，不约束整个数据表宽度 |
| 段落区分 | 首行 2em 缩进或约 0.75–1.25em 段距 | 沿文体选择，不机械叠加；引用、列表和紧凑说明可另定 |
| 字间距 | 正文通常保持默认 | 标题可微调，需观察实际字形，不以固定负值套全部字体 |

英文正文常以 1.5–1.7 行高、约 80ch 以内行宽起步；不同字形与文体需校准，不能将它直接当中文规则。字号层级按页面用途和信息密度形成，工具界面不强制大幅 display 梯度。

## 混排与换行

中西文及数字单位的间距沿项目文案约定，避免同一页面出现多种手工空格习惯。CSS 排版特性作为渐进增强，使用前核对项目目标浏览器，不把支持情况写死：

```css
.prose { line-break: strict; overflow-wrap: break-word; }
.prose h1, .prose h2 { text-wrap: balance; }
.prose p { text-wrap: pretty; }
```

需要自动中西文间距时可评估 `text-autospace`；需回退时保证内容仍可阅读，不让增强功能决定内容是否存在。

- 混排在实际字号及回退字体下看基线、字面大小和视觉重量。同字号的中英文字形可能显得一大一小，先比较字族、字重或行高，再决定是否微调；避免用统一的垂直偏移补偿所有字形。
- 多行标题先用真实字形观察行间与换行。有孤字或语义割裂且影响阅读节奏时，优先调整可用宽度、语句或平衡换行；短数字与单位确需同读时可局部保持同一行，窄到容不下时仍需允许可读地重排。固定高度和写死换行容易在长文本、字体回退及缩放时遮挡内容。
- 逐行对读或同一位置更新的数值可用等宽数字减小宽度变化，配合小数位、单位和对齐规则。独立展示数字按字形和内容选择，不需统一等宽；数值精度与口径沿[数据界面](data-ui.md)。

## 评审检查

需要完整搭配时，读取[设计组合](../assets/design-recipes.html)的适用区域：reading 将宋体正文与黑体控件分工；tool 使用一套黑体及等宽数字保持对齐；marketing 用较强标题尺度与短正文形成重点；showcase 让作品图形领先、说明退后。参数在样例 CSS 维护，不复制为本参考的第二套值。字号/行高需按实际字形、容器及语言校准；系统回退可能改变字面宽度，换字体后检查换行和层级。

只加载实际使用的字体与字重；沿项目加载策略检查文字是否不可见、回退是否导致明显重排。字体资源不可用时保留可读回退，不靠隐藏文字等字体加载。暗色文本需要结合实际字形核对字重、行高和间距，不能仅反转颜色。西文字体配对不意味着中文已被覆盖。

核对真实中文、长英文/URL、数字单位、标点断行、缩放与字体回退。中英双语标签要有信息用途，不能只是装饰；错误与按钮文案用用户语言，不展示生硬机翻。所有发现按 [评审规则](review.md) 的影响与证据定级，参数偏离先查项目约定及实际效果。
