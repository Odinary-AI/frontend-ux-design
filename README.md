# frontend-ux-design · 前端 UX 设计师

依据用户任务、页面用途和既有设计系统，完成前端 UX/UI 设计、局部迭代、只读评审与设计系统提取的 Agent Skill。

当前公开版本：**1.11.0-dev（开发版，仓库更新）**。产品入口为 [SKILL.md](SKILL.md)。

## 适合谁

需要借助 AI 设计或维护中文 Web 界面的开发者、设计师和产品团队。适用于落地页、工具后台、阅读与作品展示页面，优先延续项目已有框架、品牌和组件。

## 快速开始

克隆当前产品包（旧 Release 仍对应 1.10.0-dev）：

```sh
git clone https://github.com/Odinary-AI/frontend-ux-design.git
```

将包含 `SKILL.md` 的完整目录放入所用工具支持的 Skill 安装位置，保留 `references/`、`assets/` 与 `scripts/`。加载方式以该工具的当前文档为准。这个包不是网页应用，没有应用服务器或依赖安装步骤。

示例请求：

- “使用 frontend-ux-design，为资料管理工具设计首次创建流程，名称必填，其余稍后配置。”
- “评审这个库存页面的 UX/UI，重点检查零值、缺失值、筛选范围和窄屏读取，只审不改。”
- “保持现有设计，只修复表单错误提示和返回时的输入恢复。”
- “从已有页面代码提取设计系统，区分已观察到的规则与未验证行为。”

## 核心能力

- **设计与迭代**：从 brief、任务路径、真实内容推导结构；方向开放时比较有实质差异的小方案，已定方向和局部任务不扩大改版。
- **设计系统对齐**：将视觉、组件、交互、文案和数据表达放入同一契约，复用既有 token、资产和实现。
- **中文与数据界面**：关注中文排版、精确读数、零值和缺失、筛选范围，以及必要的窄屏操作。
- **评审与提取**：默认只审不改；区分静态线索、实际看图、运行操作和未验证项。

需要外部参照、组件或素材时，可按[精选资源](references/resource-catalog.md)查阅七项来源；优先复用项目已有系统，不默认安装第三方依赖或MCP。

## 可选静态检查器

随包提供只用 Python 标准库的 HTML/CSS 文本扫描器，需 Python 3.9 或更新版本：

```sh
python3 scripts/design-lint.py /path/to/page.html
python3 scripts/design-lint.py /path/to/site --tokens /path/to/tokens.css
```

支持 HTML/HTM/CSS 与 UTF-8（允许 BOM）。退出码0表示有效扫描无AUTO，可能仍有CHECK；1表示有AUTO待核对；2表示调用或读取失败等。它不执行页面、不请求网络，也不代表设计验收通过。解释与最终判定见[评审规则](references/review.md)。

## 验证与边界

此预发布版经过结构检查、lint回归和四类有限设计任务观察。单次新旧数据页对照没有证明普遍优于旧版；数据样例的原生下拉框方向键操作仍未验证完成。真实手机、屏幕阅读器、跨浏览器与生产业务行为需在具体项目中验证。

原型数据和占位必须明示；不会把静态扫描、截图数量或审美分数当作可用性证明。工具能力取决于宿主提供的文件、浏览器和其他工具；本包不附带浏览器、外部素材或发布服务。
